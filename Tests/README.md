# آزمون‌های پذیرش

پس از ساخت نسخه Windows این موارد بررسی شوند:

1. برنامه بدون وجود پوشه Data اجرا شود و پوشه را خودکار بسازد.
2. نوار پیشرفت از بارگذاری محلی تا TSETMC، تاریخچه، Codal و 100٪ حرکت کند.
3. بستن اینترنت باعث بسته شدن برنامه نشود و آخرین کش نمایش داده شود.
4. همه منوها صفحه مربوط را نمایش دهند.
5. فیلتر وضعیت و جستجوی نماد در اسکنر کار کند.
6. دوبار کلیک روی نماد، صفحه تحلیل همان نماد را باز کند.
7. دوبار کلیک روی اطلاعیه، فقط نشانی معتبر دامنه Codal را باز کند.
8. تنظیمات پس از بستن و اجرای مجدد برنامه حفظ شوند.
9. اجرای دوم در همان روز، تاریخچه تازه را دوباره از شبکه دریافت نکند.
10. Installer روی Windows x64 نصب، اجرا و حذف شود.

آزمون واحد خودکار برای parser پاسخ‌های TSETMC/Codal و محاسبات اندیکاتورها باید در مرحله بعد به پروژه افزوده شود.
