# منابع داده و رفتار همگام‌سازی

## TSETMC

برنامه از رابط JSON عمومی سایت TSETMC برای این موارد استفاده می‌کند:

- دیدبان بازار و آخرین وضعیت نمادها
- تاریخچه روزانه قیمت و حجم برای محاسبه اندیکاتورها

برای کاهش بار منبع، تاریخچه هر نماد حداکثر روزی یک بار دریافت می‌شود و بین درخواست‌های تاریخچه مکث کوتاه وجود دارد. پاسخ‌های 403، 429 و خطاهای 5xx با تاخیر افزایشی حداکثر سه بار تکرار می‌شوند.

## Codal

آخرین اطلاعیه‌ها از API جستجوی `search.codal.ir` دریافت می‌شوند. برنامه متن کامل گزارش‌ها و پیوست‌ها را دانلود نمی‌کند؛ فقط فراداده و نشانی گزارش ذخیره می‌شود و با دوبار کلیک، صفحه رسمی کدال باز خواهد شد.

## ذخیره محلی

تمام داده‌های قابل استفاده مجدد در مسیر زیر نگهداری می‌شوند:

```text
%LOCALAPPDATA%\BoursePilotAI\Data
```

- `market-latest.json`: آخرین دیدبان و نتایج تحلیل
- `codal-latest.json`: آخرین اطلاعیه‌های دریافت‌شده
- `History\<InsCode>.json`: تاریخچه روزانه هر نماد
- `settings.json`: تنظیمات کاربر

نوشتن فایل‌ها ابتدا در فایل موقت انجام و سپس به‌صورت اتمی جایگزین می‌شود تا قطع برنامه باعث ناقص شدن داده اصلی نشود.

## محدودیت مهم

رابط عمومی این دو سایت قرارداد تضمین‌شده و نسخه‌بندی‌شده‌ای برای برنامه‌های ثالث نیست. تغییر ساختار پاسخ باید در سرویس مربوطه اصلاح شود. برنامه هنگام خطای شبکه یا تغییر موقت منبع، آخرین کش سالم را نگه می‌دارد.
